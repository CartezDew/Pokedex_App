# Pokédex app

An Expo and React Native learning project that lists the first 20 Pokémon from [PokéAPI](https://pokeapi.co/) and opens a detail screen with type and sprite information.

## Run locally

```bash
cd pokedex
npm install
npm start
```

Use the Expo terminal menu to open the app on a simulator, device, or web browser. The app needs an internet connection to load Pokémon data.

This is a small practice app. It does not include search, favorites, or offline support.
